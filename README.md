The last text message a dying phone sends at one percent battery, in the phone's own voice: it deleted nothing, it saw everything, and its 47 open tabs die with it.

## Run it

```sh
python3 main.py
```

The program writes the one-line entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
